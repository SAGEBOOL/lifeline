# lifeline

## 人生运势命理K线趋势图

五行八卦生辰八字，娱乐🎢K线图推算平台。今日运势/穿衣指南，交友避坑。

### 核心功能

根据五行八卦和生辰八字，娱乐性的推算结果。但是结果必须要K线图的形式呈现。

- 今日穿搭指南
- 今日运势（年、月、日）
- 互动UI，鼠标（手指）移动，K线图随之变化呈现不同的数值（结果）

### 人生阶段划分

| 阶段 | 年龄范围 |
|------|----------|
| 童年 | 0–10 岁 |
| 少年 | 10–20 岁 |
| 青年 | 20–30 岁 |
| 壮年 | 30–40 岁 |
| 中年 | 40–50 岁 |
| 中老年 | 50–60 岁 |
| 花甲 | 60–70 岁 |
| 古稀 | 70–80 岁 |
| 耄耋 | 80–90 岁 |

### K线板块

在"人生运势走势图"K线板块中，增加不同年龄阶段对应的K线：

- **投资趋势**（20–80岁）
- **交友趋势**（10–80岁）
- **职场趋势**（18–60岁）

### 避坑指南板块

每个板块根据运势不同动态变化：

- 投资避坑指南
- 交友避坑指南
- 职场避坑指南
- 创业避坑指南
